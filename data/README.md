# data/

Put the live workbook here as `abcapital.xlsx` **only on private hosting** (see `docs/HOSTING.md`, Option B).

The dashboard loads `data/abcapital.xlsx` automatically if it exists. If it does not, the dashboard uses the last file loaded in that browser, or the fictional sample data.

`.gitignore` blocks `.xlsx` files so real data cannot be committed to the public repo by accident.
